本地草稿工具
1. 双击 Start.cmd，选择人物立绘。
2. 填写新角色的资源英文名，使用字母开头，可含字母、数字、下划线，最多 64 字符。
3. 选择服装结构与袖口，可选 JSON 覆盖配方。
4. 生成结果写入新的 exports 子目录，不会自动替换正式 Textures。

命令行：
python portrait_to_pawn.py "人物立绘.png" --name NewCharacter
python portrait_to_pawn.py "人物立绘.png" --name NewCharacter --recipe example_recipe.json --out "新的输出目录"
python portrait_to_pawn.py "人物立绘.png" --name NewCharacter --sleeve-style none

本地工具按立绘配色和服装模板生成三向躯干及物品图，共 4 张 PNG；不生成头部。
双臂和手省略，袖口为肩部短段或完全省略。侧背与画面外裤装采用模板推断。
example_recipe.json 是通用颜色/参数格式示例；支持 flat、shaded、fitted_tactical 渲染模式。
fitted_tactical 需要 shirt_vest 结构，并可导出 SVG 图层。
工具不自动理解任意立绘的装备布局；当前精修材质由内置 image_gen 重绘后格式化得到。

依赖与源码
Start.cmd 优先使用本机附带的 Python。换机器可用：
py -3 -m pip install -r requirements.txt
portrait_to_pawn.py：立绘分析、格式化与导出。
flat_renderer.py、fitted_renderer.py：通用躯干绘制模板。
gui.py：选图与生成界面。
python -m unittest -v test_portrait_to_pawn.py
